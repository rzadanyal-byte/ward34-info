# Ward 34 QR Webpage

## 1. सबसे पहले
`index.html` में:
- उम्मीदवार का नाम
- दल का आधिकारिक नाम
- वार्ड के तथ्यात्मक मुद्दे
- आधिकारिक चुनाव लिंक
- सार्वजनिक संपर्क विवरण

अपनी जानकारी के अनुसार बदलें।

## 2. पोस्टर
`assets/poster.jpg` को बदलकर अपनी वह image रखें जिसे सार्वजनिक रूप से दिखाने का अधिकार आपके पास है।

## 3. वेबसाइट को ऑनलाइन करें
GitHub Pages पर repository बनाकर इन files को upload करें:
- index.html
- style.css
- script.js
- assets/poster.jpg

फिर:
Settings → Pages → Deploy from branch → main → /root → Save

आपको एक URL मिलेगा, जैसे:
https://YOUR-USERNAME.github.io/ward34-info/

## 4. QR Code
QR code को FINAL LIVE URL के लिए बनाना जरूरी है।
उदाहरण:
https://YOUR-USERNAME.github.io/ward34-info/

QR बन जाने के बाद उसे poster/visiting card पर लगाएँ।

महत्वपूर्ण: local `file:///...` path का QR न बनाएं, क्योंकि दूसरे मोबाइल पर वह नहीं खुलेगा।
